接入你的应用(点开复制代码)

把 base_url 指向本代理即可自动记账;API Key 原样透传,面板零改动。若在「设置」中启用了访问令牌,请求还需带头 X-DSCD-Token: 你的令牌。

Python(openai SDK)

from openai import OpenAI

client = OpenAI(
    api_key="sk-...",                  # 你的 DeepSeek API Key(透传)
    base_url="http://127.0.0.1:8787",  # 指向本地代理,自动记账
)
resp = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "你好"}],
)

Node.js(openai SDK)

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-...",
  baseURL: "http://127.0.0.1:8787",
});
const res = await client.chat.completions.create({
  model: "deepseek-flash",
  messages: [{ role: "user", content: "你好" }],
});

curl

curl http://127.0.0.1:8787/chat/completions \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-flash","messages":[{"role":"user","content":"你好"}]}'

Key 分组统计

代理从 Authorization 自动识别调用方 Key(仅保存哈希与掩码,不落盘完整 Key);label 可自定义
Key掩码label(可编辑) 调用数费用占比

调用日志

导出 CSV
时间端点模型Key Tokens(命中/未命中/输出)工具(搜/图/抓) 其他量费用明细合计状态

价格表编辑(保存后立即生效)

单位:模型 token 为 元/百万 tokens;工具为 元/千次;OCR 元/千页;ASR 元/小时;TTS 元/万字符。写入 prices.json。

设置(API Key 仅用于查询余额)

Key 只保存在本机 data.db,用于轮询官方 /user/balance;面板不产生任何调用费用。

访问令牌(公网部署必开) 设置后:面板需登录、代理端请求需带 X-DSCD-Token: 令牌 头;环境变量 DSCD_TOKEN 优先且不可在此修改。本地单机使用可不设置。
监控偏好
Webhook 预算告警 月花费达 80% 推送 budget_warning、100% 推送 budget_exceeded(每级别每月一次);支持钉钉/飞书/企业微信机器人格式
估算口径:官方刊例价 × 每次调用返回的 usage 计数,仅供监控参考,以官方账单为准。 高峰时段 = 北京时间周一至周五 9:00–12:00、14:00–18:00。流式请求默认注入 stream_options.include_usage,关闭后未开启该选项的流式 token 用量可能无法统计(工具次数仍可统计)。
